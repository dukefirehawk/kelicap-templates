# Kelicap Starter Templates and Reference Examples

## Starter Templates

| Template Name | Comments |
| :--- | :--- |
| starter_app | A boilerplate application utilizing Kelicap directives, fully compatible with popular CSS frameworks including Bulma, Bootstrap, and Tailwind. |
| starter_m2_app | A boilerplate application featuring Kelicap directives and Material Design 2 components, provided via [**kelicap_components**](https://pub.dev/packages/kelicap_components). |
